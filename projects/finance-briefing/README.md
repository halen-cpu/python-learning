# 每日财经简报

每日早 8:00（工作日）自动生成，文件命名 `daily-YYYY-MM-DD.md`。

## 为什么建这个

金融科技专业，最大的问题不是不会学，是**离真实的市场太远**。
课本上的东西和盘面里的东西是两套语言，这个文件夹就是用来搭桥的。

## 归档用法

每天花 3 分钟扫一眼标题，感兴趣的点进去看。
周末回头翻一周的简报，找**重复出现的主题**——那才是真的在发生的事。

一个月后回看，你会发现有些宏观变量在连续影响你的专业，
而这些是你不刻意看就永远不会知道的。

## 纪律

- 每份简报的数字都必须带来源链接。没有来源的数字一律不写。
- 不预测。简报只说"发生了什么"和"数据是多少"，不猜"明天会怎样"。
- 发现某条信息连续三天出现在简报里 → 标记出来，那是值得深挖的信号。
