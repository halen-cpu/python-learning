# 广州买房压力测算器

> 项目 01 · 广东金融学院金融科技专业 · 侯ii
> 一句话：把「广州哪个区我够得着」这个模糊焦虑，换成一个能拖着玩的数字。

## 为什么做这个

买房是大多数广东金融学院学生的现实目标，但没人算得清这件事到底有多远。
刷房产APP只会让你更焦虑——几十万条房源，看完更不知道自己在哪里。

所以我做了个反过来的东西：**输入你的真实收入和首付，输出你够得着的最贵的区**。
不看绝对值，只看**月供 / 收入比**这一个指标。因为银行批贷看的是这个，你能不能睡得着也是这个。

## 怎么用

双击 `index.html`，浏览器直接打开。不需要装任何东西，不需要联网。

拖动六个滑块：
- **税后月收入** 4000 – 50000 元
- **手头首付** 0 – 200 万
- **目标面积** 30 – 200 ㎡
- **贷款年限** 10 / 15 / 20 / 25 / 30 年
- **贷款利率** 2.6% / 2.7% / 3.0% / 3.1%
- **月供收入比红线** 30% – 60%

实时重算，输出：够得着的最贵区、对应月供、压力比、首付缺口，以及攒首付需要多久。

**已知局限（写在明面上，不藏）：**
- 房价是**挂牌均价**，实际成交通常低 5–10%，且同区不同小区差异极大（天河内部能差一倍）
- 首付比例固定按 30%，实际还受公积金缴存、征信、房龄影响
- 只算了等额本息，没算等额本金、组合贷、税费、维修基金
- 未考虑未来房价涨跌。广州目前处于下行通道（全市均价从 2025-12 的 34,901 跌到 2026-10 的 27,315）

## 技术

纯 HTML + CSS + 原生 JS，零依赖零构建。

核心是一个等额本息月供函数：

```js
function monthly(principal, annualRate, years){
  const n = years*12, r = annualRate/12;
  if(r===0) return principal/n;
  const f = Math.pow(1+r, n);
  return principal*r*f/(f-1);
}
```

11 区 × 6 个参数全量重算，表格排序 + 条形图 + 分档配色（安全/吃紧/超红线）都是一遍遍历算出来的，没有硬编码任何结论。

## 我从这个项目学到什么

1. **数据源比算法重要**。月供公式是教科书里的，但「广州主流房贷利率是 LPR−50BP」这种事没人教，必须自己去查，查到了还要标来源和日期。
2. **把不确定性做成可玩的控件，而不是免责声明**。房价会跌、成交价有折让——与其写一堆免责声明，不如让用户自己拖滑块看不同假设下的结果。
3. **结论要能被反驳**。这套工具不给「你应该买哪」，只给「以你的条件，边界在哪」。决策还是人做。

## 后续可以做什么

- [ ] 接入公积金+商贷的组合贷测算
- [ ] 加入「首套/二套」区分（利率和首付比例都不同）
- [ ] 做一个「收入需要涨到多少才能上车目标区」的反向求解器
- [ ] 数据接到后端，支持每月自动更新挂牌均价
- [ ] 做一个真·投资版本：租售比 vs 贷款利率，测算「买房划算还是租房划算」

最后一条才是重点——现在广州的租售比只有 1.92%，年租金回报率低于 2.7% 的房贷利率，**租房在财务上明显优于买房**，除非你要的是户口或者稳定。这件事值得单独做个工具。
