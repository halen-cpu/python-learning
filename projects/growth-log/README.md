# 成长日志

每月 1 日 20:00 自动生成上月复盘，文件名 `YYYY-MM.md`。

## 记录什么

不是流水账，是**数据 + 结论**：

- 学习时长、连续打卡、趋势对比
- 技术栈实际进展（只记真的学会了的）
- 作品集本月推进了什么
- 下月建议，要具体到可执行

## 为什么要有这个

四年下来你会忘掉大一做过什么、什么时候开始会的。
找工作写简历时，你会需要一份"我什么时候具备了什么能力"的时间线。

这个东西平时看着没用，到大三投简历的时候是唯一能救你的东西。

## 手动补一句

每个月末如果自动生成的复盘有遗漏，手动加一句自己的感受。
机器能算时长，算不了你的状态。
