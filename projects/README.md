## 和 `../` 有什么区别

`../` 里是学习：01_hello、02_basics、猜数字——这些是我**在学**的痕迹。

这里是作品：每个项目都要满足下面的三条标准。**不满足就别放进来。**

## 收录标准（三条硬门槛，缺一不可）

1. **能一行跑起来**
   别人拿到之后，不需要配置环境、不需要改代码、不需要问你，就能跑出结果。
   纯 HTML 单文件 > 带依赖但有明确安装说明 > 需要你手把手教。

2. **有真实输出**
   必须跑在真实数据上。爬来的房价、真实的财报、真实的 API 返回。
   **不接受** `print("hello world")` 这种。数据造假 = 直接删。

3. **有 README，说清三件事**
   - 为什么做（动机，不是"练手"）
   - 数据从哪来（带来源和日期）
   - 已知局限在哪（不藏）

## 怎么开一个新项目

```
projects/项目名/
├── index.html 或 main.py    # 能一行跑起来的入口
├── README.md                # 为什么做 / 数据来源 / 已知局限
├── data/                    # 原始数据（带日期命名，如 prices-2026-10.json）
└── screenshots/             # 至少一张效果图
```

建完在上面的索引表里加一行，然后 `git push`。

## 提交纪律

- 每个项目单独一个 commit，写清楚做了什么
- 数据文件不要提交敏感的（个人信息、未公开的财务数据）
- README 里的数据来源要带**日期**，过期的数据要标注「已过期」
